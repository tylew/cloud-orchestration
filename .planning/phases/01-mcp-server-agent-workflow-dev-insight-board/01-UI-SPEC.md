## Layout Contract

### Primary focal point

The environment selector Tabs in the TopBar is the primary visual anchor. It governs all panel content by switching Firestore subscription paths, making it the single control that determines what every panel displays.

### Page structure

The Insight Board is a single-page dashboard at route `/insight/:projectRefId`.

```
+----------------------------------------------------------+
| TopBar: Project name + env selector (Tabs)               |
+----------------------------------------------------------+
| Left Column (50%)          | Right Column (50%)          |
| +------------------------+ | +------------------------+ |
| | ProjectStatePanel      | | | TerraformPanel         | |
| +------------------------+ | |                        | |
| | ResourceListPanel      | | |                        | |
| |                        | | +------------------------+ |
| +------------------------+ | | DeployPanel            | |
| | ValidationPanel        | | |                        | |
| |                        | | +------------------------+ |
| +------------------------+ | | ActivityFeed           | |
+----------------------------------------------------------+
```

- Two-column layout using CSS grid: `grid-cols-2` with `gap-8` (32px)
- Each panel is a Card component with heading, optional status badge, and content area
- Panels stack vertically within each column with `gap-6` (24px)
- Page padding: 48px top, 32px sides
- Minimum viewport width: 1024px (developer tool, not mobile)
- No responsive mobile layout (developer desktop tool)

### Panel behavior

- All panels are read-only (no edit controls, no buttons, no forms)
- All panels subscribe to Firestore via `onSnapshot` and update in real-time
- Loading state: skeleton placeholder (use `animate-pulse` on muted background blocks)
- Connection loss: muted banner at top of page with error state copy

## Interaction Contract

| Interaction | Behavior |
|-------------|----------|
| Environment switch | Tabs component at top; switching env re-subscribes all Firestore listeners to the new env path |
| Panel scroll | ScrollArea on TerraformPanel (code block), DeployPanel (log output), ActivityFeed |
| Terraform code | Monospace font (`font-mono`), no syntax highlighting required (plain text in `<pre>` block) |
| Deploy logs | Monospace font, auto-scroll to bottom on new entries, muted timestamp prefix per line |
| Activity feed | Newest entries at top, each entry shows: timestamp + operation description |
| Validation issues | Grouped by node, sorted error-first then warning, each row shows severity badge + node name + message |
| Resource list | Table with columns: Type (icon + label), Name, Status (badge), Validation (badge) |

### States

| State | Visual Treatment |
|-------|-----------------|
| Loading | Skeleton blocks with `animate-pulse` on muted background |
| Connected | No indicator (default state) |
| Disconnected | Amber banner at page top: "Connection lost..." |
| Reconnected | Banner auto-dismisses after 2 seconds |
