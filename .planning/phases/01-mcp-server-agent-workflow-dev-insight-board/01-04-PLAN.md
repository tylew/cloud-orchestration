_SLUG_PREFIXES = {"cloud_run": "cr", "service_account": "sa", "vpc": "vp", ...}

def _generate_slug(node_type: str) -> str:
    prefix = _SLUG_PREFIXES.get(node_type, "nd")
    suffix = ''.join(random.choices(string.ascii_lowercase + string.digits, k=6))
    return f"{prefix}-{suffix}"

def _dump_node(node: BaseNode) -> dict:
    data = node.model_dump(mode="json", by_alias=True)
    if isinstance(node.config, BaseModel):
        data["config"] = node.config.model_dump(mode="json")
    return data

    - Per D-05: Takes project_ref_id and env_name as params.
    - Per D-06: Auto-provisioning is eager, triggers on add.
    - Steps:
      1. Build node dict: `{"name": name, "type": node_type, "config": config or {}, "depends_on": depends_on or []}`
      2. Generate slug using `_generate_slug(node_type)` (copy the helper from nodes.py handler, including _SLUG_PREFIXES)
      3. Set `node_dict["slug"] = slug`
      4. Validate via `BaseNode.model_validate(node_dict)` — catch ValidationError, return format_error
      5. Check slug uniqueness via `blueprint_store.get_node()`
      6. Persist via `blueprint_store.save_node()`
      7. Load existing nodes: `blueprint_store.list_nodes()`
      8. Call `auto_provision_for_node(node_dict, existing_nodes)` — get created list
      9. For each auto-created node: generate slug, validate, persist via blueprint_store
      10. Run validation on full blueprint (same pattern as nodes.py handler: build Envelope, call validate_blueprint_by_slug, persist)
      11. Return formatted response with: primary node data, auto_created nodes list (per D-09), validation results, and any warnings
    - Per D-07: Auto-provisioned nodes have `auto_provisioned: True` in their data
    - Per D-09: Response includes list of auto-created nodes

    **update_node(project_ref_id: str, env_name: str, slug: str, config: dict | None = None, depends_on: list[str] | None = None, name: str | None = None)** -> str
    - Load existing node, merge updates, validate, persist
    - After update, recompute IAM roles if depends_on changed: call `infer_iam_roles()` and update the node's SA roles
    - Run validation, return updated node + validation

    **delete_node(project_ref_id: str, env_name: str, slug: str)** -> str
    - Per D-10: If node has `auto_provisioned: True`, include warning about potential breakage
    - Call `blueprint_store.delete_node()` to get list of deleted slugs
    - Run validation on remaining blueprint
    - Return deleted slugs + validation results

    **list_nodes(project_ref_id: str, env_name: str = "dev")** -> str
    - Load all nodes + validation doc
    - Return formatted list with: slug, type, name, validation status (errors/warnings count), auto_provisioned flag
