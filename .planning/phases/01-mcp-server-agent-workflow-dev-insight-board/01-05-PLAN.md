    1. Create `packages/mcp/tools/secrets.py` with these tools (per D-01, AGT-03):

       GCP project ID retrieval pattern (used by all secret tools that need the GCP project):
       ```python
       from packages.platform.store import projects as projects_store

       # Inside each tool that needs gcp_project_id:
       project = projects_store.get_project(get_tenant_id(), project_ref_id)
       if not project:
           return format_error("not_found", f"Project {project_ref_id} not found")
       env_entry = projects_store.get_env_entry(project, env_name)
       if not env_entry:
           return format_error("not_found", f"Environment {env_name} not found")
       gcp_project_id = env_entry.get("gcp_project_id")
       if not gcp_project_id:
           return format_error("not_provisioned", f"Environment {env_name} has no GCP project ID")
       ```

       **create_secret(project_ref_id: str, env_name: str, secret_name: str, secret_value: str)** -> str
       - Loads project to get GCP project ID from env entry (using pattern above)
       - Creates secret in Secret Manager via `gcp_secret_manager.create_secret(gcp_project_id, secret_name)`
       - Adds version with value via `gcp_secret_manager.add_secret_version(gcp_project_id, secret_name, secret_value)`
       - Saves metadata to Firestore via `secrets_store.save_secret()`
       - Returns confirmation with secret name (value NOT echoed back)

       **list_secrets(project_ref_id: str, env_name: str = "dev")** -> str
       - Lists secrets from Firestore metadata store
       - Returns formatted list with: name, created_at (values masked per existing behavior)

       **get_secret(project_ref_id: str, env_name: str, secret_name: str)** -> str
       - Gets GCP project ID from env entry (using pattern above)
       - Gets secret value from Secret Manager (latest version)
       - Returns secret name and value

       **delete_secret(project_ref_id: str, env_name: str, secret_name: str)** -> str
       - Gets GCP project ID from env entry (using pattern above)
       - Deletes from Secret Manager and Firestore metadata
       - Returns confirmation

       All follow the pattern from secrets.py handler but call store/GCP functions directly.

    1. Create `packages/mcp/tools/builds.py` with these tools (per D-01, AGT-05):

       **trigger_build(project_ref_id: str, env_name: str, node_slug: str)** -> str
       - Follow the pattern from builds.py handler:
         Load project, get GCP project ID, get node data, submit Cloud Build job
       - Per D-19: Check for in-progress builds, return actionable error: "Build blocked: build {id} already in progress for {slug}. Wait for completion or check status."
       - Returns build_id and status

       **get_build_status(project_ref_id: str, env_name: str, build_id: str)** -> str
       - Gets build status from Firestore build record
       - Returns: build_id, status (queued/building/success/failure), node_slug, started_at, finished_at

       **get_build_logs(project_ref_id: str, env_name: str, build_id: str)** -> str
       - Retrieves build output logs for a completed (or failed) build.
       - Use existing functions from `packages/platform/gcp/cloud_build.py`:
         `get_build_plan_output(host_project_id, build_id)` for Terraform plan output and
         `get_build_apply_output(host_project_id, build_id)` for Terraform apply output.
         These read from GCS at `gs://{CB_SOURCE_BUCKET}/results/{build_id}/plan.txt` and `apply.txt`.
       - Get `host_project_id` from `os.environ.get("GCP_PROJECT_ID", "pl4m-host-dev")` (same pattern as builds.py handler).
       - Also include `log_url` from the Firestore build record (via `build_store.get_build(...)`) so the agent
         can link to the Cloud Build console if GCS logs are unavailable.
       - Return formatted string with: build_id, status, plan output (if available), apply output (if available), log_url.
       - If build is still in progress (status not terminal), return status + log_url only with message
         "Build still in progress. Logs available after completion."
       - Wrap in try/except, return format_error on failure.

       **list_builds(project_ref_id: str, env_name: str = "dev")** -> str
       - Lists builds from Firestore
       - Returns formatted list with: build_id, node_slug, status, timestamp

    2. Create `packages/mcp/tools/deploy.py` with these tools (per D-01, AGT-06):

       **trigger_deploy(project_ref_id: str, env_name: str = "dev")** -> str
       - Follow the pattern from projects.py deploy handler:
         Load blueprint, validate (block if errors per D-21), check env is provisioned,
         check no in-progress deploy (per D-19)
       - Per D-19: Concurrency guard errors formatted as actionable messages:
         "Deploy blocked: deploy {id} in progress. Check status with get_deploy_status."
         "Deploy blocked: blueprint has {N} validation errors. Fix errors before deploying."
         "Deploy blocked: environment '{env}' is not provisioned."
       - On success: create deploy record in Firestore, then launch the deploy orchestrator
         in a background thread using `threading.Thread(target=_run_deploy, args=(...), daemon=True).start()`.
         This mirrors FastAPI's `BackgroundTasks.add_task()` behavior but works outside the ASGI context.
         Import `_run_deploy` from `packages.platform.deploy_orchestrator` (or `deploy_service` -- read both
         files to find the actual function that the projects.py handler calls).
       - Return deploy_id and initial status ("queued")

       **get_deploy_status(deploy_id: str)** -> str
       - Gets deploy record from Firestore
       - Returns: deploy_id, status, env, started_at, finished_at, error (if any)

       **get_deploy_logs(deploy_id: str)** -> str
       - Since MCP tools can't stream SSE, load completed build logs from Cloud Build
         or the deploy record's log field
       - Returns: log output as string (may be truncated if very long)
       - If deploy is still in progress, return current status + any available log lines

       **list_deploys(project_ref_id: str, env_name: str | None = None)** -> str
       - Lists deploy records, optionally filtered by env
       - Returns formatted list with: deploy_id, env, status, timestamp
