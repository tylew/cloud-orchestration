  <behavior>
    IAM Role Mappings (iam_mappings.py):
    - ("Read", "cloud_sql") -> "roles/cloudsql.client"
    - ("Write", "cloud_sql") -> "roles/cloudsql.client"
    - ("Read", "firestore") -> "roles/datastore.user"
    - ("Write", "firestore") -> "roles/datastore.user"
    - ("Read", "bigquery") -> "roles/bigquery.dataViewer"
    - ("Write", "bigquery") -> "roles/bigquery.dataEditor"
    - ("Read", "bigtable") -> "roles/bigtable.reader"
    - ("Write", "bigtable") -> "roles/bigtable.user"
    - ("Read", "gcs_bucket") -> "roles/storage.objectViewer"
    - ("Write", "gcs_bucket") -> "roles/storage.objectAdmin"
    - ("Invoke", "cloud_run") -> "roles/run.invoker"
    - ("Invoke", "cloud_function") -> "roles/cloudfunctions.invoker"
    - ("Emit", "pubsub_topic") -> "roles/pubsub.publisher"
    - ("Enqueue", "cloud_task_queue") -> "roles/cloudtasks.enqueuer"
    - ("Read", "secret_manager") -> "roles/secretmanager.secretAccessor"
    - ("Write", "secret_manager") -> "roles/secretmanager.secretVersionAdder"
    - Unknown combos -> None
    - infer_iam_roles(node_data, all_nodes) -> set of IAM role strings

    Auto-Provisioning (auto_provision.py):
    - auto_provision_for_node(node_data, existing_nodes) for non-compute type -> {"created": [], "warnings": []}
    - auto_provision_for_node(node_data, existing_nodes) for cloud_run -> creates SA node, returns {"created": [sa_node]}
    - auto_provision_for_node(node_data, existing_nodes) for cloud_run with cloud_sql dep -> creates SA + VPC + subnet + connector
    - auto_provision_for_node(node_data, existing_nodes) for cloud_run with firestore dep -> creates SA only (no networking)
    - auto_provision_for_node when VPC already exists -> reuses existing, does not create duplicate
    - auto_provision_for_node when SA already exists for this compute node -> skips SA creation
    - All auto-created nodes have `auto_provisioned: True` in their data
    - SA node name derived from compute node name: `sa-{compute_name}`
    - Networking nodes use fixed names: `default-vpc`, `default-subnet`, `default-connector`
  </behavior>
  <implementation>
    1. Create packages/core/iam_mappings.py:
       - IAM_ROLE_MAP: dict mapping (ActionType_value, NodeType_value) tuples to GCP IAM role strings
       - PRIVATE_ACCESS_TYPES: set = {NodeType.CLOUD_SQL, NodeType.BIGTABLE} (per D-11)
       - def get_iam_role(action_type: str, target_node_type: str) -> str | None
       - def infer_iam_roles(node_data: dict, all_nodes: list[dict]) -> set[str]:
         Walk the node's internalGraph steps, for each step that references another node,
         look up (action_type, target_type) in IAM_ROLE_MAP. Also check depends_on for
         implicit Read access. Return deduplicated set of role strings.

    2. Create packages/core/auto_provision.py:
       - def auto_provision_for_node(node_data: dict, existing_nodes: list[dict]) -> dict:
         Returns {"created": list[dict], "warnings": list[str]}
       - Internal helpers:
         _needs_service_account(node_data, existing_nodes) -> bool
         _create_sa_node(compute_name: str) -> dict
         _needs_private_access(node_data, existing_nodes) -> bool
         _has_existing_networking(existing_nodes) -> bool
         _create_networking_stack() -> list[dict]
       - SA node structure: {"name": f"sa-{name}", "type": "service_account", "slug": f"sa-{slug_suffix}",
         "config": {"account_id": f"sa-{name}"}, "depends_on": [], "auto_provisioned": True}
       - VPC: {"name": "default-vpc", "type": "vpc", "config": {"auto_create_subnetworks": False}, "auto_provisioned": True}
       - Subnet: {"name": "default-subnet", "type": "subnet", "depends_on": ["default-vpc"],
         "config": {"ip_cidr_range": "10.8.0.0/28", "region": "us-central1"}, "auto_provisioned": True}
       - Connector: {"name": "default-connector", "type": "vpc_connector", "depends_on": ["default-subnet"],
         "config": {"region": "us-central1", "ip_cidr_range": "10.8.0.0/28"}, "auto_provisioned": True}
       - The compute node's depends_on is updated to include the SA slug and (if networking) the connector slug

    3. Write tests FIRST (RED), then implement (GREEN), then refactor if needed.
  </implementation>
