## Cross-Phase Integration Gaps

### GAP-1: cloud_dns not creatable via MCP (MISSING-1)

**Affects:** AGT-02, DNS-01
**Location:** `packages/mcp/tools/nodes.py` `_SLUG_PREFIXES` dict
**Issue:** Phase 2 added `cloud_dns` to the registry, but Phase 1's MCP `add_node` tool has a hardcoded `_SLUG_PREFIXES` allowlist that doesn't include it. `add_node(node_type="cloud_dns")` returns a validation error.
**Fix:** Add `"cloud_dns": "dn"` to `_SLUG_PREFIXES` in `packages/mcp/tools/nodes.py`

### GAP-2: ResourceListPanel missing cloud_dns label (MISSING-2)

**Affects:** AGT-11
**Location:** `apps/web/src/components/insight/ResourceListPanel.tsx` `TYPE_LABELS`
**Issue:** The insight board's resource list renders `cloud_dns` as the raw enum string instead of "Cloud DNS". Cosmetic but indicates Phase 2 wasn't wired into the frontend.
**Fix:** Add `cloud_dns: "Cloud DNS"` to `TYPE_LABELS`

### GAP-3: by_node output parsing for multi-underscore names (BROKEN-1)

**Affects:** OUT-04
**Location:** `packages/platform/deploy_orchestrator.py` `_parse_terraform_outputs()`
**Issue:** `rsplit("_", 1)` strategy splits `my-dns_name_servers` as `node="my-dns_name"`, `attr="servers"` instead of `node="my-dns"`, `attr="name_servers"`. Affects cloud_dns (`name_servers`, `dns_name`) and cloud_sql (`connection_name`). Flat `outputs` dict is correct; only `by_node` grouping is wrong.
**Fix:** Use output naming registry or match against known node names from the blueprint instead of naive underscore splitting.
